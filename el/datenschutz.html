Φιλοξενία

Ο ιστότοπος φιλοξενείται στο GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, ΗΠΑ). Κατά την επίσκεψη, το GitHub επεξεργάζεται τεχνικά απαραίτητα στοιχεία, όπως τη διεύθυνση IP σου, για να εμφανίσει τον ιστότοπο και να τον προστατεύσει από επιθέσεις. Νομική βάση είναι το έννομο συμφέρον μας για ασφαλή λειτουργία (άρθρο 6 παρ. 1 στοιχ. στ΄ ΓΚΠΔ). Περισσότερα στη δήλωση απορρήτου του GitHub: GitHub General Privacy Statement.
